# Contributing

Thanks for your interest in Jinshuju Skill.

This repository contains the official Jinshuju Skill for working with Jinshuju forms, data, and workflow automation through MCP. We welcome documentation fixes, usage examples, and improvements that make the skill easier and safer to use.

## How to contribute

- For documentation fixes, open a pull request.
- For bugs or unclear behavior, open an issue with reproduction steps.
- For feature ideas, open an issue describing the use case first.
- For product support or account-specific questions, contact support@jinshuju.net.

## Before submitting

Please make sure your contribution:

- Does not include API keys, secrets, access tokens, private form data, or customer data
- Keeps examples clear, realistic, and safe
- Preserves the existing skill structure under `skills/jinshuju/`
- Includes verification notes when changing scripts, references, or tool behavior

## Local usage

Review the skill files under:

```text
skills/jinshuju/
```

For setup and examples, see:

- [`skills/jinshuju/references/guide.md`](skills/jinshuju/references/guide.md)
